A segment tree over a fixed array supporting O(log n) point updates and O(log n) range-sum queries, built recursively with a flat `vector` sized `4n` (node `i` has children `2i+1`/`2i+2`). Queries short-circuit on no-overlap and full-overlap so only O(log n) nodes are visited per call, instead of the O(n) a naive prefix-sum-with-rebuild approach would cost after every update. Run with `g++ -std=c++17 -Wall main.cpp -o out && ./out`.
