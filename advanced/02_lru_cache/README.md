A proper O(1) get/put LRU cache combining a doubly linked list (ordered by recency, with sentinel head/tail nodes) and an `unordered_map` for O(1) key lookup. When the cache is at capacity, the node right before the tail sentinel — the least recently used — gets evicted. This is the classic interview question, kept correct and minimal. Run with `g++ -std=c++17 -Wall main.cpp -o out && ./out`.
