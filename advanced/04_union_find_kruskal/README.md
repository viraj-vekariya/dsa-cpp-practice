A disjoint-set union-find with path compression and union by rank, used to implement Kruskal's minimum spanning tree algorithm: sort all edges by weight, then greedily add each edge whose endpoints are in different components. Runs on a small hardcoded 6-node weighted graph and prints the resulting MST edges and total weight. Run with `g++ -std=c++17 -Wall main.cpp -o out && ./out`.
