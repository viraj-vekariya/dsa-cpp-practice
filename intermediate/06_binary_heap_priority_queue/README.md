A binary min-heap built on a flat `vector` (no `std::priority_queue`), supporting O(log n) push/pop and O(1) peek via sift-up/sift-down over the implicit array layout (node `i`'s children are `2i+1`/`2i+2`, same indexing scheme as the segment tree). Templated on a `Compare` functor so it works for plain `int`s or, as demonstrated, a struct. The demo uses it to merge k sorted lists into one sorted output in O(N log k) — only k elements are ever in the heap at once, so this beats concatenating everything and sorting (O(N log N)) whenever k is much smaller than N. Run with `g++ -std=c++17 -Wall main.cpp -o out && ./out`.
